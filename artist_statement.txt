In this project, I got interested in how different squares go together in different ways. When I was doing my pattern searching, I found that it was interesting how all of the different square/rectangle-based patterns felt so different but were so similar as well. I tried leaning into that for this project with using rounded corners and random amounts of squares on each column and row set before each generation. It also refreshes every 5 seconds using 5 * 30 to set it to the appropriate value.
